- **Manufacturer spelling.** Time Module is written 3 ways: “TMI (Time Module) (Seiko-Japan)”, “Time Module (Seiko-Japan)”, “TMI (Seiko-Japan) / BAO JIE”. Shown everywhere as “Time Module (TMI)”.
- **Accuracy figure.** All 92 quartz references carry the same “±20 Sec/Month (Typ., Quartz)” figure. It is a typical value, not the rating of each calibre.
- **Strap / bracelet label.** Cerruti, Police and Ducati label every reference “BRACELET”, including silicone, leather and satin straps. The catalogue now derives Strap or Bracelet from the material.
